# Definition of Done – Team 5 WeatherCLI

Gültig ab Sprint 1. Sie gilt für **jede** Story gleichermassen — im Unterschied zu
den Akzeptanzkriterien, die nur für eine einzelne Story gelten.
Eine Story gilt erst als „fertig", wenn alle sechs Punkte erfüllt sind.

1. **Akzeptanzkriterien erfüllt** — jedes Kriterium der Story wurde einmal von Hand
   im Terminal durchgespielt, inklusive des Fehlerfalls.
2. **Code im Repository auf `main`** — über einen Pull Request gemerged, keine
   offenen lokalen Änderungen.
3. **Von einer zweiten Person angeschaut** — der Pull Request hat mindestens ein
   Review-Approval von einem anderen Teammitglied.
4. **Läuft bei allen im Team** — jedes Teammitglied hat `main` ausgecheckt und den
   Befehl der Story auf dem eigenen Rechner einmal erfolgreich ausgeführt.
5. **Board aktualisiert** — die Story steht in der Spalte „Done", die Aufgaben
   darunter sind geschlossen.
6. **README beschreibt den Befehl** — der neue Befehl bzw. das neue Flag ist mit
   einem Beispielaufruf im README dokumentiert.

**Überprüfung:** An Modultag 5 schauen wir diese Liste erneut an und schärfen sie
mit dem, was wir in Sprint 1 tatsächlich eingehalten haben.
